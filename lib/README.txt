Put the SQLite JDBC driver JAR in this folder.

Download it (free) from Maven Central:
https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/

Open the newest version folder (for example 3.46.1.3/) and download the file
named sqlite-jdbc-<version>.jar  (NOT the -sources or -javadoc jar).

Rename it to sqlite-jdbc.jar (optional, but makes the run commands simpler).
